ATC Collector

Firmware for the ESP32-C3 OLED board: shows readings from Xiaomi thermometers running pvvx ATC_MiThermometer.

Your browser can't flash devices. Use desktop Chrome or Edge. Flashing needs a secure (https) page.

Steps

  1. Open this page in desktop Chrome or Edge (Firefox and Safari lack Web Serial).
  2. Connect the board by USB-C, click Connect, and pick the "USB JTAG/serial debug unit" port.
  3. If no port shows up, hold BOOT, tap RST (or re-plug), release BOOT, and try again.
  4. After flashing, press RST. The OLED shows "Scanning" until a sensor is received.

Linux: your user must be in the dialout (or uucp) group to access the port.
